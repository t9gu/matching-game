# 🎮 单词连连看 - Nintendo风格

一个为6岁儿童设计的手势控制单词学习游戏，结合MediaPipe手势识别和赛博朋克视觉效果。

## 📋 项目简介

这是一个基于Web的交互式单词学习游戏，孩子通过手势控制来连接英语单词和对应的图片，在游戏中学习英语单词。

## ✨ 核心特性

### 🎯 游戏玩法
- **4×4网格布局**：16个卡片，包含8个英语单词和8个对应的emoji图片
- **手势连线**：用食指指向卡片进行选择和连线
- **配对消除**：正确配对后卡片消失，播放庆祝动画和音效
- **计时挑战**：记录完成时间和连击数

### 👆 手势控制
- **MediaPipe Hands**：实时手部追踪
- **食指指向**：用食指指向卡片进行选择
- **赛博朋克骨骼**：手部骨骼带有发光追踪效果
  - 青色(#0ff)、粉色(#f0f)、黄色(#ff0)渐变线条
  - 关节点发光效果
  - 食指尖端特殊高亮

### 🎨 视觉设计
- **Nintendo风格UI**：明亮渐变背景，圆润卡片设计
- **动画效果**：
  - 标题弹跳动画
  - 卡片悬停放大
  - 配对成功旋转消失
  - 庆祝emoji动画
- **配色方案**：
  - 背景：紫色渐变(#667eea → #764ba2)
  - 按钮：粉红渐变(#f093fb → #f5576c)
  - 卡片：白色渐变，选中时金黄色

### 🔊 音效系统
- **Web Audio API**：动态生成音效
- **成功音效**：上升音调，三连音庆祝
- **错误音效**：下降音调提示
- **即时反馈**：选择卡片时的提示音

## 🎮 游戏说明

### 游戏流程
1. **启动游戏**：点击"开始游戏"按钮
2. **允许摄像头**：浏览器会请求摄像头权限，请允许
3. **手势控制**：
   - 伸出食指，其他手指收起
   - 将食指指向卡片进行选择
   - 连续选择两张卡片进行配对
4. **配对规则**：
   - 正确：单词和对应的图片配对成功
   - 错误：不匹配的卡片会恢复
5. **完成游戏**：配对完所有8对卡片

### 计分系统
- ⏱️ **时间**：记录完成游戏的时间
- ✅ **已配对**：显示当前配对数 / 总数(8)
- 🎯 **连击**：连续正确配对的次数

## ⚙️ 配置说明

### MediaPipe配置
```javascript
maxNumHands: 1              // 只追踪一只手
modelComplexity: 1          // 中等复杂度模型
minDetectionConfidence: 0.7 // 检测置信度
minTrackingConfidence: 0.7  // 追踪置信度
```

### 摄像头配置
```javascript
width: 1280                 // 摄像头宽度
height: 720                 // 摄像头高度
```

## 📝 开发说明

### 添加新单词
在 `game.js` 的 `getWordDatabase()` 方法中添加：

```javascript
{ word: 'newword', translation: '中文', emoji: '🎯' }
```

### 修改游戏难度
调整卡片数量（需要修改HTML和CSS）：
- 简单：3×3 (9张卡片，4.5对)
- 中等：4×4 (16张卡片，8对) ← 当前
- 困难：5×5 (25张卡片，12.5对)

### 自定义样式
在 `index.html` 的 `<style>` 标签中修改CSS变量和样式。

## 🐛 常见问题

### 摄像头无法启动
- 检查浏览器权限设置
- 确保使用HTTPS或localhost
- 尝试刷新页面

### 手势识别不准确
- 确保光线充足
- 手部完全在摄像头视野内
- 保持手部稳定

### 卡片选择不灵敏
- 调整 `minDetectionConfidence` 参数
- 确保食指伸直，其他手指收起
- 手指移动速度不要太快
